# P2-2 传输验收 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 socket-server / http-server 加上 wire 级验收脚本并接入 ctest。

**Architecture:** 脚本 `tests/acceptance/transport_accept.sh`（仿 `tests/acceptance/apps_accept.sh` 的 `set -e` + `case` 断言风格）驱动两个现成 example；C 探针对端 `probe_sock` 随测编译、不装机。不断言时序，只断言回显字节与退出码。

**Tech Stack:** C（探针，仿 `examples/client/main.c` 传参风格）、sh、ctest。

### Task 2: C 探针 probe_sock.c

**Files:**
- Create: `tests/acceptance/probe_sock.c`
- Modify: `tests/CMakeLists.txt`（加 target，不装机）

- [ ] **Step 1: 写探针**

TCP connect 到 `argv[1] host argv[2] port`，发送 `argv[3]` 负载（echo 用 JSON-RPC
一行，http 用 POST 字节），读到 EOF 或 5 秒超时后把收到的字节原样写到 stdout，
exit 0。只用 POSIX socket + `select` 超时，不引 mcpkit 库。

- [ ] **Step 2: 接 CMake（随测编译）**

```cmake
add_executable(probe_sock acceptance/probe_sock.c)
```

不 `install()`。仿 `tests/CMakeLists.txt` 现有 `add_executable` 写法。

- [ ] **Step 3: 编译验证**

Run: `cmake -S . -B build >/dev/null 2>&1 && cmake --build build --target probe_sock 2>&1 | grep -ciE "warning|error:"`
Expected: `0`

### Task 3: transport_accept.sh

**Files:**
- Create: `tests/acceptance/transport_accept.sh`（`chmod +x`，仿 apps_accept.sh 28 行结构）

> 实测修正（2026-10-12）：`MCPKIT_BUILD_SOCKET` 默认 ON，`MCPKIT_BUILD_HTTP`
> 默认 OFF，`timeout` 可用。因此拆成两个 test：socket（默认配置即跑，
> 60→61）与 http（仅 HTTP 配置跑）。脚本取 `<mode> <server> <probe>`，
> mode=socket|http；server 二进制不存在则 FAIL（由 CMake 条件保证存在才注册）。

- [ ] **Step 1: 写脚本**

```sh
#!/bin/sh
# argv: <mode:socket|http> <server-binary> <probe_sock>
set -e
# socket: 起服务(端口 18765/28765/38765 顺序重试) → probe 发 initialize 一行 →
#   断言回显含 result → 杀服务
# http: 起服务(stdin/stdout 文件背载) → probe 发 POST 字节(照抄
#   tests/unit/test_http_serve.c:140-160 握手) → 断言含 200 + 握手体 → 杀服务
# 任何一步失败 echo FAIL:<原因> + exit 1；结尾 echo "transport <mode> acceptance OK"
```

端口重试：`for p in 18765 28765 38765`，probe 连上即用。杀服务用 `$!` + `kill`
（sh 兼容，不用 bashism）。timeout 有则包 10 秒，没有则跳过并告警。

- [ ] **Step 2: 本地跑通（分 mode）**

Run: `./tests/acceptance/transport_accept.sh socket ./build/examples/socket-server ./build/tests/probe_sock`
Expected: `transport socket acceptance OK`
Run: `./tests/acceptance/transport_accept.sh http ./build-http/examples/http-server ./build-http/tests/probe_sock`
Expected: `transport http acceptance OK`

### Task 4: ctest 接线 + 全量验证

**Files:**
- Modify: `tests/CMakeLists.txt`（仿 cli_acceptance 块）

- [ ] **Step 1: 条件接线**

```cmake
if(MCPKIT_BUILD_SOCKET AND MCPKIT_BUILD_EXAMPLES)
  add_test(NAME transport_socket_acceptance
           COMMAND ${CMAKE_CURRENT_SOURCE_DIR}/acceptance/transport_accept.sh
                   socket
                   ${CMAKE_BINARY_DIR}/examples/socket-server
                   ${CMAKE_BINARY_DIR}/tests/probe_sock)

```
