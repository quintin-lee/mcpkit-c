## T1：版本策略层 `version.h`（新增）

**文件**：新增 `include/mcpkit/protocol/version.h`。

代码：

```c
#ifndef MCPKIT_PROTOCOL_VERSION_H
#define MCPKIT_PROTOCOL_VERSION_H

#include <stdbool.h>

typedef enum {
    MCP_PROTO_NONE = 0,            /* 未知/未协商 */
    MCP_PROTO_2024_11_05,
    MCP_PROTO_2025_03_26,
    MCP_PROTO_2025_06_18,
    MCP_PROTO_2025_11_25,
    MCP_PROTO_2026_07_28,
} mcp_proto_version_t;

const char *mcp_proto_version_string(mcp_proto_version_t v); /* NONE→NULL */
mcp_proto_version_t mcp_proto_version_parse(const char *s);  /* 未知/NULL→NONE */
bool mcp_proto_at_least(mcp_proto_version_t v, mcp_proto_version_t min);

#endif
```

实现放 `src/protocol/initialize.c`（避免新增 .c 文件的 CMake 改动；保持“版本工具随协商表同文件”）。三个函数均为纯查表/比较，无分配。

验证：`mcp_proto_version_parse("2025-11-25")==MCP_PROTO_2025_11_25`；`mcp_proto_at_least(MCP_PROTO_2026_07_28, MCP_PROTO_2025_11_25)==true`；`parse("1999")==NONE`；`string(NONE)==NULL`。

## T4：route_initialize 写 negotiated；discover 按 negotiated 回显
