- [ ] **Step 1: 用以下精确文本替换 `docs/module-reference.md` 第 688-700 行**

~~~markdown
### `dispatcher.h`
Per-session message queue plus single-step processing.
```c
mcp_queue_t  *mcp_queue_create(ctx);
void          mcp_queue_destroy(ctx, mcp_queue_t *q);
mcp_status_t  mcp_queue_push(ctx, q, session, msg);
mcp_status_t  mcp_queue_pop(ctx, q, session_out, msg_out);
size_t        mcp_queue_size(ctx, const mcp_queue_t *q);
mcp_status_t  mcp_server_process_one(ctx, server, q, resp_out);
```
Ownership: the queue TAKES the message on `mcp_queue_push` success (`MCP_OK`);
on error the message is NOT consumed and the caller retains it. `mcp_queue_pop`
hands ownership to the caller on `MCP_OK`. `mcp_server_process_one` destroys the
message internally after dispatch; on `MCP_OK` `*resp_out` is a caller-owned
response (NULL when the message was a notification).
Push fails with `MCP_ERR_NOMEM` once the queue holds `MCP_QUEUE_MAX_LEN`
(1024) messages — the host must drain before pushing more. The queue borrows
the session pointer; it does not own sessions.
~~~
